# IMERA Website, No Images Required

This version uses only HTML, CSS, and JavaScript. The hero and project artwork are generated entirely with CSS.

## Publish
1. Replace your existing HTML, CSS, and JS files with these files.
2. Update the LinkedIn and GitHub `#` links in `contact.html`.
3. Confirm or replace `contact@imera.games`.
4. Push to GitHub Pages.

The `assets` folder can be deleted because this version does not require image files.
